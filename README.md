# Bungee Biker

A 1:1 clone of the classic game Elasto Mania.

## Setup

```bash
pip install -r requirements.txt
```

## Run

```bash
python main.py
```

## Controls

- **Up Arrow**: Accelerate
- **Down Arrow**: Brake
- **Left Arrow**: Rotate counter-clockwise
- **Right Arrow**: Rotate clockwise
- **Space**: Turn around
- **ESC**: Quit
